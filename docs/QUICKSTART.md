# Quick Start Guide

## For Administrators

### First Login
1. Navigate to `/public/login.php`
2. Login with default credentials: `admin` / `password`
3. **IMMEDIATELY** change your password in Profile Settings
4. Configure system settings in Admin Panel → System Config

## Common Tasks

### Changing Your Password
1. Login to your account
2. Go to Profile Settings
3. Enter current password
4. Enter new password twice
5. Click "Update Password"

### Customizing Your Interface
1. Go to Profile Settings
2. Select your preferred colors
3. Choose font size (small/medium/large)
4. Select layout style
5. Click "Save Settings"

### Uploading Documents
1. Go to Documents section
2. Click "Upload New Document"
3. Select document type
4. Choose file (PDF, JPG, PNG, DOC)
5. Add description
6. Click "Upload"

### Sending Messages
1. Go to Messages
2. Click "New Message"
3. Select recipient
4. Enter subject and message
5. Add attachments if needed
6. Click "Send"

## Frequently Asked Questions

**Q: I forgot my password. What do I do?**
A: Contact your administrator or case manager to reset it.

**Q: Can I access the system from my phone?**
A: Yes! The system is fully responsive and works on mobile devices.

**Q: How secure is my information?**
A: All data is encrypted and protected. Only authorized staff can access client information.

**Q: Can I change the colors and fonts?**
A: Yes! Each user can customize their interface in Profile Settings.

**Q: How long are my documents stored?**
A: Documents are stored securely as long as you're in the program.

**Q: Who can see my messages?**
A: Only you and the recipient can see your messages. Administrators may access for support purposes.
